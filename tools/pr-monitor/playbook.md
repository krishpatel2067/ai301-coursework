# Playbook: [Student name]

## Response rules

- Answer a reviewer's point in the first sentence.
- Never use emojis.
- No more than one exclamation point in the response (when functioning as punctuation, not as syntax
  like `!my_bool`).

## Staleness thresholds

- Wait for 1 week before nudging.
- Does not count for responses, which have to go out as soon as possible.

## Nudge etiquette

- Content of the nudge: "Just following up about this: <subject/question>." or similar.
- Ping only one maintainer! (e.g. @oliverschuerch for `swisspost/design-system`)

## Walk-away criteria

- Only close a PR is there is absolutely no maintainer activity on the thread (no merge, feedback,
  or close), _and_ there is another PR fixing the same issue which is getting more maintainer
  attention.
- If these conditions are satisfied, wait 1 month before closing my own PR.
- Close note: "I will close this PR since another promising PR already solves the issue" or
  something similar as fits the situation.
